## Authentication

The CLI uses OAuth with tokens stored in your OS keyring.

```bash
# Login (opens browser)
webex login

# Check auth status
webex auth status

# List stored accounts
webex auth list

# Switch between accounts
webex auth switch user@example.com
```

You can also use a token directly:

```bash
webex --token "$WEBEX_TOKEN" calling people list
```

### Read-only mode

Use read-only mode when an AI agent or script should be able to read your Webex data but not change it.

```bash
webex login --read-only
```

This login requests only read scopes (`webex config get read-only-scopes` lists them) and turns on read-only mode:

- Stored logins with write access are deleted from the OS keyring. Other programs running as you can read the keyring, so leaving those logins there would let them bypass read-only mode.
- `PUT`, `PATCH`, `DELETE`, and uploads are refused before they are sent. `POST` is allowed only for a fixed list of query endpoints that take their filters in the request body, such as `cc search` and recording queries. Webex also rejects writes because the token has no write scopes.
- `--token` and `$WEBEX_TOKEN` are refused, because the CLI cannot check the scopes of a token it did not create.
- `auth switch`, `--user`, and folder defaults work only for users who logged in with `--read-only`.
- `webex mcp serve` does not register the `webex_write` tool.

To leave read-only mode, run `webex login` from an interactive terminal and confirm the prompt. The command refuses to run without a terminal, so an agent running shell commands cannot leave read-only mode on its own. Setting `WEBEX_READ_ONLY=1` turns on the same checks for one process. It never turns them off.

The OAuth integration must have every read-only scope registered. If login fails with `invalid_scope`, set a list that matches your integration with `webex config set read-only-scopes "<scopes>"`. Only read scopes are accepted.

## Command Structure

```
webex admin <resource> <action> [flags]       # Webex Admin APIs
webex calling <resource> <action> [flags]     # Webex Calling APIs
webex cc <resource> <action> [flags]          # Contact Center APIs
webex device <resource> <action> [flags]      # Webex Device APIs
webex meetings <resource> <action> [flags]    # Webex Meetings APIs
webex messaging <resource> <action> [flags]   # Webex Messaging APIs
```

## Global Flags

| Flag | Description |
|------|-------------|
| `--token <token>` | Override authentication |
| `--user <email>` | Use a specific authenticated user |
| `--organization <orgId>` | Override org ID |
| `--output json\|table\|csv\|raw` | Output format (default: json) |
| `--debug` | Show HTTP request/response details |
| `--paginate` | Auto-paginate list results (ignored by commands that return one object) |

## Admin Examples

```bash
# List people in the organization
webex admin people list --max 10

# List licenses
webex admin licenses list

# List roles
webex admin roles list
```

## Calling Examples

```bash
# List people
webex calling people list --max 10

# Get your own details
webex calling people get-my-own

# List locations
webex calling locations list

# List devices
webex calling devices list
```

## Contact Center Examples

CC commands auto-populate `--orgid` from your login:

```bash
# List sites
webex cc site list

# List teams
webex cc team list

# List users
webex cc users list

# List queues
webex cc contact-service-queue list

# List entry points
webex cc entry-point list

# With filtering
webex cc site list --filter='name=="Site A"'

# With pagination
webex cc entry-point list --paginate
```

## Device Examples

```bash
# List devices
webex device devices list

# List workspaces
webex device workspaces list
```

## Meetings Examples

```bash
# List meetings
webex meetings meetings list

# List recordings
webex meetings recordings list --paginate

# List transcripts
webex meetings transcripts list
```

## Messaging Examples

```bash
# List rooms
webex messaging rooms list

# List messages in a room
webex messaging messages list --room-id "ROOM_ID"

# List teams
webex messaging teams list
```

## Output Formats

```bash
# Pretty JSON (default)
webex cc site list

# Table format
webex cc site list --output=table

# CSV format
webex admin people list --output=csv

# Raw JSON
webex cc site list --output=raw

# Save to file
webex cc site list > sites.json
```

## Discover Commands

Use `--help` at any level to see available commands:

```bash
webex --help
webex admin --help
webex calling --help
webex cc --help
webex device --help
webex meetings --help
webex messaging --help
webex cc users --help
```
